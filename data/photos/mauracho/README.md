# 珠洲市真浦町 現地写真（2026-09-23）

森林緩衝帯シミュレーターの検証用に、珠洲市真浦町で撮影した現地写真と、
各写真の EXIF から抽出した位置情報です。

## 内容

| ファイル | 内容 |
|---|---|
| `IMG_*.JPG` | 現地写真 86 枚（iPhone 15 Pro Max、長辺 2048 px に縮小、EXIF は原本のまま保持） |
| `位置情報一覧.csv` | 全 92 件（写真 86・動画 6）のファイル名・緯度・経度・標高・撮影日時 |
| `撮影位置.geojson` | 撮影地点（Point）と撮影経路（LineString）。QGIS 等の GIS ソフト用 |
| `撮影位置.kml` | Google マイマップ / Google Earth 用 |
| `撮影位置マップ.html` | 地理院タイル上に全地点を表示する単体マップ（ブラウザで直接開けます） |

動画 6 本（MOV、計 364 MB）は容量のためリポジトリには含めていません。
位置情報は `位置情報一覧.csv` に記録済みです。

## 撮影範囲

- 緯度 37.46937 – 37.47388 / 経度 137.09218 – 137.10188
- 標高 4.9 m – 113.1 m
- 撮影時刻 2026-09-23 06:56 – 08:50

集落の海側（標高 5–15 m）から東の谷筋を標高 108 m まで登って折り返し、
海岸へ戻ったのち南側の別ルートで標高 113 m まで登る、往復 2 本のルートです。

## 位置情報の抽出方法

`tools/extract_gps.py` で再生成できます。

```bash
pip install 'exifread==2.3.2'
python3 tools/extract_gps.py            # リポジトリ内の写真 86 枚
python3 tools/extract_gps.py <元フォルダ>  # 動画 6 本を含む 92 件
```

引数を省略するとこのフォルダを走査するため、動画を含まない 86 件の結果になります。
コミット済みの `位置情報一覧.csv` は動画 6 本を含む 92 件版です。

写真は exifread で EXIF の GPS タグを読み、度分秒（DMS）を 10 進数に変換しています。
動画は exifread が QuickTime を読めないため、
`com.apple.quicktime.location.ISO6709` アトムを直接パースしています。

縮小時に EXIF は保持しており、縮小後の 86 枚から再抽出した座標が
原本と完全に一致することを確認済みです。
